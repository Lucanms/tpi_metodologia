# Registro de uso de IA

**Herramienta:** ChatGPT y Gemini.
**Para qué la usamos:** Principalmente como apoyo para consultar conceptos, resolver dudas de configuración con java y git y mejorar la redacción del informe. No generamos todo el código con IA; lo fuimos guiando y adaptando a lo que necesitaba el TP.

**Consultas principales que hicimos:**

1. **Diagnóstico:** Le pasamos el código inicial y le pedímos que nos ayude a identificar los 8 code smells y cómo se relacionaban con SOLID.
2. **Refactoring:** Le consultamos cómo documentar bien el "antes y después" de los cambios (ej. pasar de 9 parámetros a un `record DatosSolicitud`).
3. **Errores técnicos:** Nos ayudó a entender por qué saltaba el error `ClassNotFoundException` al correr los tests.
4. **Git:** Le preguntamos cómo organizar los commits y tags de las etapas para que quede prolijo en GitHub.
5. **Redacción:** Nos ayudó a resumir las conclusiones para que no queden tan largas y ha armar el checklist de code review.

*Todo el código y las pruebas fueron revisados, entendidos y probados por nosotros antes de subirlos.*
